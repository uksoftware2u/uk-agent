常见问题

先弄清楚，再开始。

AI Agent 和普通聊天机器人有什么不同？

聊天机器人主要负责对话。我们规划的 Agent 方案会在授权范围内，进一步查询资料、整理单据草稿及触发工作流；能执行哪些动作，取决于已连接的工具与审批规则。

需要更换现有的 AutoCount 吗？

方案以连接现有业务系统为方向，而不是一律更换。我们会先确认 AutoCount 版本、模块、API 支持和授权，再确定可整合的范围。

会不会未经确认就开单或改资料？

方案设计会把关键写入动作放在审批之后，并由服务端验证权限、参数与重复请求。具体审批、日志及异常处理规则，需在项目上线前配置和验收。

数据一定不会离开公司吗？

不一定。云端或混合方案可能将必要资料传送给模型或服务供应商。本地方案也需要检查外部调用；我们会先厘清数据流向、保留策略及访问范围，不把“本地”当成零风险保证。

网站上线就等于 AI Agent 已部署了吗？

不是。此网站提供方案介绍、流程演示与咨询入口。真实 AI Agent、MCP Server、UK Web API、AutoCount 授权连接与维护，需要另行评估、配置及部署；模型用量、硬件和软件授权等费用也另计。
